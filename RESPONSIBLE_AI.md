# Responsible use

ATLAS is a decision-support prototype, not a forecasting or policy-authority system. Its scenario outputs are deterministic indicators derived from bounded public-data fixtures and explicit assumptions.

The system does not treat missing observations as zero, does not fabricate unsupported domain data, and labels derived and provisional relationships. Reviewers should inspect dataset coverage, retrieval status, assumptions, uncertainty, and provenance before using an output.

Exports preserve the backend result and its limitations. They should not be presented as predictions, causal proof, or a substitute for domain experts.
